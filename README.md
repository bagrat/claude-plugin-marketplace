# Bagrat's Claude Code plugins

```
/plugin marketplace add bagrat/claude-plugin-marketplace
```

| Plugin | What | Install |
| --- | --- | --- |
| [desk](https://github.com/bagrat/claude-plugin-desk) | A Desk per project: one private page that keeps you informed and holds what needs you, kept by one Claude session. | `/plugin install desk@bagrat` |

Each plugin lives in its own repo; this one only lists them (`.claude-plugin/marketplace.json`).
